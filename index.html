Project Architecture & Data Flow

1. Ingestion → PDF document pipeline
2. ETL Parser → RecursiveCharacterTextSplitter (chunk: 1000, overlap: 200)
3. Vectorization → Embedding weights generated from model
4. Database Storage → Persisted Chroma / Vector indices mapping
5. Semantic Query → Maximum Marginal Relevance (MMR) retriever filters
6. Generation → Context window loaded into LLM and answered

Deep Development Log

Role SummaryAI Specialist, LangChain Integrator
Key FeaturesFile ingestion system, semantic indexer, hallucination evaluation
Primary Code StackPython, LangChain, OpenAI Embeddings, ChromaDB, FastAPI

System Challenges: Default semantic search models retrieved bloated, repetitive context spans. This depleted token limits and caused hallucinations when documents contained contradictory tabular reports.

Engineering Solution: Implemented Maximum Marginal Relevance (MMR) retrieve query filters to force chunk diversification. Added an intermediate schema scoring chunk quality on relevance before forwarding to the generation engine.

Learning Outcome: Mastered the granular mechanics of text embedding vector spacing, memory buffering contexts, and system-level prompt boundaries.
